## Как они себя ведут

Подложка показывается только после успешной загрузки: пока файла нет,
фигура `#club-top` остаётся спрятанной, и над меню справочной просто
ничего. Пустая рамка три к одному над меню была бы хуже, чем её
отсутствие.

Медаль встаёт **на место** номера, а не рядом с ним: колонка места одна
на весь список, и значок сбоку развалил бы столбец имён ровно на
тройке, которую смотрят первой. Пока картинки нет — в строке обычный
номер 1, 2, 3; строка при этом остаётся кнопкой и открывает карточку
бойца.

Исходные 1254 px в CSS не ставятся: на экране медаль 44 px, у первого
места 56 px. Рисуются через `object-fit: contain` — разная форма краёв
не срежет.

Подложка идёт `object-fit: cover` с фокусом по центру, пропорция 3:1,
не выше 190 px; низ растворяется в фоне страницы градиентом, иначе её
край режет экран ровной линией поперёк.

Всё это живёт в `CLUB_ART`, `dressClub`, `paintClubTop` и `dressRank`
в `card.js`, стили — в блоках «подложка справочной» и «кликабельная
строка бойца и подиум рейтинга» в `card.css`.
