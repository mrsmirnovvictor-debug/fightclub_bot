# Материалы миссии «Чёрный пуск»

Эта папка — **данные**, по которым ходит сервер, а не копия исходного
архива.

| Файл | Кто читает |
|---|---|
| `mission_manifest.json` | `bot/game/blackout.py` на старте: 64 комнаты, 76 переходов |
| `scenario.md` | люди: исходный сценарий миссии |
| `maps/route_*.svg` | люди: семь схем этажей, 1280×680 |
| `assets.json`, `links.md` | справка: реестр картинок и прямые ссылки |

**Картинок здесь нет нарочно.** Все 38 растровых файлов лежат в том же
бакете, что и весь арт клуба, в папке `zombiemission`; адрес бакета
один на проект и правится в `bot/game/art.py`. Класть девять мегабайт
картинок в репозиторий ради того, что уже выложено, незачем.

Координаты комнат в манифесте относятся к схемам `maps/route_*.svg`
(холст 1280×680), а не к дверям на художественной иллюстрации
`maps/station_overview.jpg`. Интерфейс рисует схему узлов по этим
координатам, а обзорная картинка остаётся иллюстрацией.

Проверить карту: `python3 scripts/validate_blackout_map.py`.
