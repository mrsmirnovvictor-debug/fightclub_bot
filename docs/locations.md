- Формат: JPEG, RGB
- Исходный размер каждой карты: `941 × 1672` px
- Ориентация: portrait, соотношение сторон около 9:16
- Камера: объёмный верхний/isometric ракурс

## Правило отображения и нажатий

Показывать всю карту через `object-fit: contain`, без обрезки. Основная форма hotspot — `polygon`: замкнутый многоугольник по видимому силуэту здания, заданный массивом нормализованных точек `[x,y]` (диапазон 0–1, начало координат в левом верхнем углу самого изображения). Точки перечислены по часовой стрелке; последнюю точку с первой замыкает клиент. `rect` оставлен как fallback для старого интерфейса и быстрой грубой проверки. Если вокруг изображения появились letterbox-поля, сначала вычесть их смещение и только затем нормализовать координаты касания.

Пиксельная точка многоугольника вычисляется так: `px=x*941`, `py=y*1672`. Попадание проверяется обычным point-in-polygon. Для визуальной подсветки рисовать тот же polygon, а не его bounding box.

Рекомендуется принимать касание внутри силуэта здания, а перед выполнением действия визуально подсвечивать его контур. На маленьком экране допустимо невидимо расширить область касания на 1.5% ширины изображения, но видимая обводка обязана оставаться по исходному polygon. Общая зона выхода со всех карт в выбор района: `{x: 0.35, y: 0.84, w: 0.30, h: 0.14}` (нижний центральный проход).

## Рекомендованная модель данных

Каждая карта: `id`, `image`, `hotspots`. Каждый hotspot: `id`, `polygon`, `rect` (fallback), `action`. Для перехода между районами нижняя зона вызывает `open_location_picker`; здания вызывают соответствующий экран или рейд. Не привязывать зоны к размеру DOM-элемента напрямую и не использовать координаты viewport — только координаты фактически отрисованного изображения.
