- Камера: объёмный верхний/isometric ракурс

## Правило отображения и нажатий

Показывать всю карту через `object-fit: contain`, без обрезки. Hotspot хранить в нормализованных координатах `x`, `y`, `w`, `h` (диапазон 0–1, начало координат в левом верхнем углу самого изображения). Если вокруг изображения появились letterbox-поля, сначала вычесть их смещение и только затем нормализовать координаты касания.

Пиксельный прямоугольник вычисляется так: `left=x*941`, `top=y*1672`, `width=w*941`, `height=h*1672`.

Рекомендуется принимать касание по всему прямоугольнику здания, а перед выполнением действия визуально подсвечивать его контур. Общая зона выхода со всех карт в выбор района: `{x: 0.35, y: 0.84, w: 0.30, h: 0.14}` (нижний центральный проход).

## Рекомендованная модель данных

Каждая карта: `id`, `image`, `hotspots`. Каждый hotspot: `id`, `rect`, `action`. Для перехода между районами нижняя зона вызывает `open_location_picker`; здания вызывают соответствующий экран или рейд. Не привязывать зоны к размеру DOM-элемента напрямую и не использовать координаты viewport — только координаты фактически отрисованного изображения.
